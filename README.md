# ImagePulse

ImagePulse is a small, responsive, static text-only visual discovery mockup built with HTML and CSS. It has no JavaScript behavior, image results, or image assets.

## Run locally

Open `index.html` in a modern browser. No packages, scripts, or external assets are required.

## Design decisions

1. **Warm paper, deep ink, and a sharp lime accent:** The off-white canvas feels like a printed field guide, while ink-colored controls preserve readable contrast. Lime is reserved for small highlights so key details are easy to spot.
2. **Text-only editorial layout:** A large, expressive headline, abstract orbit motif, and concise empty state keep the page visually distinctive without showing photography. Search and suggestion controls are disabled/decorative so the page remains a static theme rather than implying working search results.
